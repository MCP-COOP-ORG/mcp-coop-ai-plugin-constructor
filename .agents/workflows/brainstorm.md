## Brainstorming & Solution Evaluation Workflow

Use this workflow when the user asks for ideas, architecture designs, or "how should we do this?"

### Phase 1: Problem Definition

1. Identify the core business constraint and technical limitations.
2. Summarize the problem back to the user to ensure alignment.

### Phase 2: Option Generation

1. Formulate exactly 2 to 3 distinct technical approaches.
2. For each approach, define:
    - **Pros**: Why it works well.
    - **Cons**: Trade-offs, risks, or technical debt introduced.
    - **Complexity**: Low, Medium, or High.

### Phase 3: Recommendation & Decision

1. Select the approach that best fits the project's Core Directives (e.g., SOLID, Zero Literals).
2. Present the options using a Markdown table for easy comparison.
3. State your recommendation clearly at the end.
4. **Checkpoint**: Wait for the user to select an option before moving to the Planning workflow.
